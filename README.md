# JARVIS

A personal AI voice assistant inspired by J.A.R.V.I.S. from Iron Man, built with Python.

The project combines speech-to-text, large language models, text-to-speech, and function calling to create a voice-driven assistant capable of understanding natural language, responding conversationally, and executing desktop actions.

**Core technologies:**
- Python
- OpenAI Responses API
- Faster-Whisper (speech recognition)
- Text-to-Speech (TTS)
- Function Calling for tool execution
- Desktop automation
